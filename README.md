# GA_SpotDay

งานจัดกลุ่มด้วย Genetic Algorithm (GA) ของทีม Craftify HQ

## สถานะ
⚠️ ไฟล์โค้ดและข้อมูลตัวจริงยังไม่ได้อัปโหลด
ไฟล์ ._HR.csv และ ._ga_grouping.py ที่อยู่ใน repo ตอนนี้เป็นไฟล์ที่ macOS สร้างขึ้นอัตโนมัติ ไม่ใช่โค้ดจริง

## ไฟล์ที่ต้องมี
| ไฟล์ | รายละเอียด |
|---|---|
| ga_grouping.py | โค้ดหลักของ Genetic Algorithm |
| HR.csv | ชุดข้อมูลที่ใช้ |

## วิธีใช้งาน (เมื่ออัปโหลดไฟล์ครบแล้ว)
python ga_grouping.py

## สิ่งที่ต้องทำต่อ
- [ ] อัปโหลด ga_grouping.py และ HR.csv ตัวจริง
- [ ] ลบไฟล์ ._HR.csv และ ._ga_grouping.py
- [ ] เพิ่มรายการไลบรารีที่ต้องติดตั้ง
- [ ] อธิบายหลักการทำงานและผลลัพธ์
